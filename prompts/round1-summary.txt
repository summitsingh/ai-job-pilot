Behavior decisions:
- Wire codegate, budgeted_chat and heartbeat, rather than relabel as experimental.
- Retry an explicit expired/invalid code response; block ambiguous code submits.
- Missing stdin stays blocked for a human. Requeues stop the current lane run.
- Live CDP watchdog cannot prove an ambiguous submit safe to retry, so it blocks.
  Initial JS fallback requires an explicit selector miss, not a lost CDP response.
- Model cancellation is cooperative. An in-flight socket read cannot be forcibly
  killed; its timeout is capped, late results discarded and no later calls made.
- Tracker update edits local JSONL only; remote update is not claimed. Existing
  Notion databases need ID, Response Date and Furthest Stage properties.
- Substantive MINOR findings deferred. Alphanumeric gate validation was a trivial
  consequence of changing coordinate; historical audit punctuation was normalized
  solely to satisfy the hard no-em-dash constraint.
